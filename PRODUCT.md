# Cleaner

Windows x64 desktop utility for reviewing cleanup candidates, explicitly applying selected file/system operations, inspecting disk usage and recovering quarantined files. The existing WPF application and CLI share the Core layer. Russian and English are supported.

The primary audience includes people without technical knowledge. The normal journey is selection, analysis, review, confirmation, execution and an honest report. Quarantining files is the default and does not reclaim space on the same volume. Permanent deletion cannot be undone by Cleaner. Expert actions may affect Windows operation and require meaningful warnings.

The desktop has six primary destinations: Cleanup, Optimization, Startup, System, Data protection and Disk. History, What's new and Settings are secondary destinations. Settings preserve language, theme, density and other preferences. Automatic cleanup and Windows startup registration are opt-in. Active applications, user exclusions and recovery state remain relevant across themes.

UI mockups are visual references, not a source of functionality, numerical data, compatibility claims or performance promises. Public release readiness requires repeatable isolated checks and real Windows validation; automated tests alone do not prove every system action safe.
