# Cleaner 1.1.0-beta.4 — комплект для тестеров / tester package

## Русский

Обновлён состав архива для Windows x64. Внутри только приложение, необходимые данные, README на русском и английском и уведомления о лицензиях зависимостей. Документы по разработке и внутренние отчёты доступны в репозитории, в папке docs.

- Проверка SHA-256 необязательна и описана в руководстве.
- История beta.3 и предыдущих версий сохранена в «Что нового?».
- Формы для ошибок и общего отзыва доступны по ссылке ниже.

Скачайте ZIP в Assets и распакуйте полностью; Data должна оставаться рядом с Cleaner.App.exe. .NET включён. Beta не подписана. Начните с интерфейса и анализа без очистки; системные действия проверяйте в отдельной Windows VM со снимком. Все возможности beta.3 сохранены.

[Русское руководство](https://github.com/Sking32/Cleaner/blob/master/README.ru.md) · [Ошибки и отзывы](https://github.com/Sking32/Cleaner/issues/new/choose)

## English

A focused Windows x64 package containing the app, required data, Russian and English READMEs, and dependency license notices. Developer documents and internal reports are available in the repository's docs directory.

- SHA-256 verification is optional and explained in the guide.
- What's new retains beta.3 and earlier releases.
- Separate bug and feedback forms are linked below.

Download the ZIP under Assets and extract everything; keep Data beside Cleaner.App.exe. .NET is included. The beta is unsigned. Start with the interface and analysis without cleanup; use a disposable Windows VM with a snapshot for system actions. All beta.3 features are retained.
