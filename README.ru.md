# Cleaner для Windows

Русский · [English](README.md)

**Текущая beta: 1.1.0-beta.3.** Приложение для анализа очистки, просмотра твиков Windows, управления автозагрузкой и службами, восстановления файлов из карантина. Это тестовый выпуск: системные действия ещё требуют проверки на разных сборках Windows. Cleaner не обещает ускорить любой компьютер.

## Скачать и запустить

1. Откройте [Releases](https://github.com/Sking32/Cleaner/releases) и выберите нужную beta. В блоке **Assets** скачайте `Cleaner-1.1.0-beta.3-win-x64.zip`. Автоматические архивы “Source code” содержат исходники, а не готовое приложение.
2. Сравните SHA-256 архива с приложенным файлом `.zip.sha256`: в PowerShell выполните `Get-FileHash -Algorithm SHA256 .\Cleaner-1.1.0-beta.3-win-x64.zip`. Совпадение проверяет целостность файла, но само по себе не доказывает безопасность программы.
3. Распакуйте ZIP целиком в обычную папку с доступом на запись. Папка `Data` должна оставаться рядом с `Cleaner.App.exe`. Не запускайте EXE прямо из архива.
4. Запустите `Cleaner.App.exe`. В x64-сборку включён .NET. Нужна Windows с поддержкой .NET 10/WPF; совместимость отдельных системных действий ещё не подтверждена на всех сборках Windows. Для ARM64 нужны отдельная сборка и проверки; macOS и Linux не поддерживаются.

Если beta ещё не опубликована, запросите ZIP у автора. Пока первый релиз не создан, готовых файлов в Releases может не быть. Установщик для этой сборки не требуется.

Beta не имеет цифровой подписи: Windows может предупредить о незнакомом приложении. Проверьте источник и контрольную сумму. Не отключайте антивирус, SmartScreen и защиту Windows ради запуска; при сомнении остановитесь и напишите автору.

## Первый запуск и восстановление

При первом запуске появляется памятка безопасности. Её открытие не запускает очистку, применение твиков и создание точки восстановления.

- **Создать точку восстановления** предложит права администратора, если их нет. После подтверждения UAC Cleaner перезапустится; в новом окне снова нажмите создание точки. Отказ от UAC оставит текущее приложение открытым; точка не создаётся.
- Нужна включённая защита системы. Windows может отказать, если точка создавалась за последние 24 часа. Cleaner не меняет эти правила, расписания и параметры защиты. При ошибке памятка объяснит, как вручную открыть защиту системы.
- Точка помогает откатить системные файлы и настройки Windows, но не возвращает удалённые личные файлы. Важные документы сохраните отдельно. [Инструкция Microsoft по восстановлению системы](https://support.microsoft.com/en-us/windows/experience/backup-recovery/system-restore).
- **Понятно, продолжить** позволяет знакомиться с приложением без создания точки и не отменяет отдельные защиты опасных действий. Ознакомление запоминается для текущего профиля Windows. Памятку можно снова открыть: **Настройки → Безопасность и точка восстановления**. Пользователи предыдущих beta тоже увидят новую памятку один раз.

На первом запуске используется **язык интерфейса Windows**: русский → русский, английский → английский, другие языки → английский. Раскладка клавиатуры и формат даты язык приложения не определяют. В настройках доступны **Как в Windows**, **Русский** и **English**. Ручной выбор имеет приоритет; после изменения нужен перезапуск.

## Что проверить сначала

Начните с переходов, размеров окна, поиска, настроек, языка, версии в шапке, нижних кнопок **История** и **Что нового?** Поиск команд открывается через `Ctrl+K`.

На странице **Очистка** выберите **Анализ без очистки** и просмотрите размеры, примеры путей и причины пропусков. Анализ читает данные без перемещения и удаления. Реальная очистка запускается отдельно. Обычные файлы обычно перемещаются в карантин: перенос на том же диске не освобождает место. Некоторые системные операции удаляют данные окончательно. Удаление карантина уничтожает его содержимое.

Твики, управление службами и незнакомые системные действия проверяйте в отдельной Windows VM со снимком. Отмена прекращает дальнейшую работу, но не отменяет уже сделанное. Метка небольшого риска не гарантирует безопасность для каждого компьютера.

Настройки, история, данные восстановления и карантин находятся в `%LOCALAPPDATA%\Cleaner`, журналы — в его папке `Logs`. Сохраняйте данные восстановления до проверки результата. Это не изолированный portable-профиль: новая распакованная сборка использует существующие данные этой учётной записи. Перед запуском CLI закройте GUI — у них общие данные восстановления.

## Как сообщить об ошибке

Создайте [GitHub issue](https://github.com/Sking32/Cleaner/issues) или напишите автору лично. Укажите:

- Версию приложения, редакцию и сборку Windows, архитектуру и масштаб экрана.
- Язык интерфейса, страницу, шаги повторения и наличие прав администратора.
- Ожидаемый и фактический результат; при необходимости приложите снимок экрана.
- Для точки восстановления: был ли отменён UAC, включена ли защита системы и создавалась ли точка недавно.

Перед отправкой проверьте снимки и отчёты: там могут быть имя пользователя, личные пути и названия файлов. Не публикуйте карантин, бэкапы реестра и полный профиль настроек. Приложение само не отправляет сообщение об ошибке. Для чувствительных данных используйте личный канал.
