# Cleaner 1.1.0-beta.3 — первый запуск и подготовка тестирования

13 октября 2026.

## Что изменено

- При первом открытии профиля Windows показана памятка безопасности с объяснением анализа, карантина, окончательного удаления и системных рисков.
- Предложено создание точки восстановления. Это отдельное действие пользователя, без автоматической очистки или изменения защиты Windows. Обычный запуск больше не предлагает UAC сам по себе.
- Если нужны права, подтверждённый перезапуск ожидает завершения предыдущего процесса и открытия данных. После перезапуска памятка открывается даже для уже ознакомившегося пользователя; создание точки снова выбирается вручную.
- Используется существующее создание точки через Windows PowerShell с проверкой появления новой записи. Частота, расписание и защита системы не меняются. Ошибка не помечается успехом. Успешная точка учитывается общим механизмом защиты для этого запуска.
- Ознакомление сохраняется только после «Понятно, продолжить». При сбое сохранения флаг возвращается назад; повреждённые настройки не перезаписываются. Закрытие памятки через окно не считается ознакомлением.
- Пока памятка открыта, инструменты недоступны; пока точка создаётся, нельзя продолжить, создать вторую или закрыть приложение. Памятку можно повторно открыть из настроек.
- Автоматический язык соответствует Windows CurrentUICulture (языку интерфейса), а не раскладке. Русский → ru, остальные → en; явный ru/en имеет приоритет. Режим «Как в Windows» сохраняет автоматический выбор.
- Выпущена запись beta.3 в RU/EN истории с сохранением beta.2, beta.1 и исходной 1.0.0.
- README.md стал английским пользовательским руководством; README.ru.md — русским. Старый технический README сохранён в DEVELOPMENT.md. Добавлены PUBLISHING.md, RELEASE_NOTES.md и двуязычная форма Issues. Оба README включены в portable ZIP.

## Проверки

- Сборка: без ошибок и предупреждений.
- 428 изолированных тестов: App 47, CLI 31, Core 350. Среди них 19 новых случаев: культуры языка, ручной/автоматический выбор, старые и повреждённые настройки, сохранение ознакомления, отсутствие автоматического создания, успех/ошибка/повтор точки, UAC-отказ в заглушке и блокировка продолжения во время работы.
- Изолированный WPF-хост: RU/EN; памятка в 1360×860, 1120×700 и 1000×640. Проверены доступность кнопок, блокировка инструментов, сохранение флага, возврат из настроек и принудительное открытие после запроса повышения прав. Точка и UAC заменены явными заглушками.
- Реальный Cleaner.App.exe, Windows PowerShell Checkpoint-Computer, UAC и защита системы не запускались. Снимки WPF не заменяют проверку настоящего DPI Windows.

## Вручную перед публичной публикацией

В отдельной Windows VM: свежий профиль RU/EN, UAC согласие/отказ, возврат памятки после перезапуска, включённая/отключённая защита системы, новое создание и ограничение недавней точки, проверка появления точки средствами Windows. Проверить реальные 125/150/200% DPI. Если публикуется системная очистка/оптимизация, отдельно проверить нативные действия и восстановление.

Для публикации использовать GitHub Pre-release и готовые ZIP/SHA-256. Лицензия проекта остаётся решением автора; до открытой публикации выбрать LICENSE. После фиксации изменений пересобрать пакет с того же коммита, что тег релиза. Приложение не подписано; лицензионные уведомления зависимостей включены. Публикация, отправка сообщений тестировщикам и изменение удалённого репозитория в этой работе не выполнялись.
