# Cleaner 1.1.0-beta.2 — правка интерфейса

Дата: 13 октября 2026.

- «История» и «Что нового?» вынесены из основных вкладок в нижний блок бокового меню. Кнопки имеют подписи, показывают текущую страницу и блокируются при выполнении операции вместе с остальной навигацией.
- На странице «Система» удалены повторяющиеся карточки загрузки CPU, ОЗУ и свободного места. Верхняя панель метрик и раскрывающиеся сведения о компьютере сохранены; список служб получил больше места.
- Версия рядом с названием в шапке и заголовке окна читается из сборки.
- В историю обновлений добавлена запись 1.1.0-beta.2 на русском и английском. Записи 1.1.0-beta.1 и исходной версии 1.0.0 сохранены.
- Обновлены инструкции для тестирования друзьями. Сборка содержит EXE со встроенным .NET и папку Data.

## Проверки

- Сборка решения и визуального хоста: 0 ошибок и предупреждений.
- Изолированные тесты: 409 успешно (App 28, CLI 31, Core 350), без пропусков. Первый запуск тестового хоста в ограниченном sandbox не установил локальное соединение; его остановили и успешно повторили с той же изоляцией данных вне ограничения соединения.
- Визуальный хост с заглушками: RU/EN, все 9 страниц, размеры 1360×860 и 1120×700, снимки при масштабе 100/200%. Это рендеринг WPF, а не проверка реального переключения DPI Windows.
- Проверены версия в заголовках, отсутствие дополнительных страниц среди шести основных инструментов, доступность нижних кнопок в небольшом окне, их переходы и подсветка, отсутствие дублирующих метрик на странице «Система», сохранение настроек и PressedForeground у кнопок.
- При 1120×700 автоматическая проверка насчитала 7 полностью видимых строк служб (ранее минимум составлял 6).

Реальный Cleaner.App.exe и системные операции в этом этапе не запускаются. Друзьям нужно вручную проверить первый запуск, переходы через нижнее меню и Ctrl+K, выбранную стартовую страницу, версию в шапке, историю обновлений и список служб при разных размерах окна и масштабах Windows. Совместимость системных операций по-прежнему требует отдельной проверки; ограничения основного обновления перечислены в BETA_REPORT.md.
