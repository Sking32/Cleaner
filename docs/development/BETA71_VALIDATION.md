# Cleaner 1.1.0-beta.7.1 — проверка исправления

Дата: 2026-10-14. Небольшое обновление beta.7, не стабильный релиз.

## Изменения

- Восстановлены названия «Мягкая», «Стандартная», «Глубокая» / Soft, Standard, Deep. Исправлены устаревшие подсказки: глубокий профиль не обещает DISM, мягкий не описывается как выбор только старых пользовательских файлов.
- Пересмотренный в beta.7 состав пресетов сохранён. Профиль «Для игроков» остаётся доступным. Системные действия не добавлены в автоматически выбранные профили.
- Добавлены «Все» и «Ничего» рядом с заголовком пресетов. Они меняют только галочки доступных категорий текущего режима: 45 в обычном, 56 в экспертном. Отключённые категории не выбираются. В экспертном режиме «Все» включает системные действия; это объясняется в подсказке и примечании.
- Массовый выбор снимает выделение встроенного/пользовательского пресета и сбрасывает устаревшие результаты анализа. Повторный выбор пресета возвращает его состав. Сам выбор файловые действия не запускает.
- Кнопки массового выбора и список пресетов недоступны во время операции. В обработчиках кнопок есть дополнительная проверка состояния.
- Проверка обновлений распознаёт дополнительный номер исправления: beta.7 < beta.7.1 < beta.7.2 < beta.7.10 < beta.8. Существующие версии beta, rc и стабильные продолжают сравниваться. Неправильные/слишком большие номера отклоняются.
- Версия в шапке и история обновлений: 1.1.0-beta.7.1. Предыдущие записи сохранены. FileVersion: 1.1.0.7.
- Обновлены README RU/EN, чек-лист тестировщика и описание пре-релиза в RELEASE_NOTES.md.

## Быстро проверить вручную

1. Распаковать весь ZIP, закрыть предыдущую версию, проверить beta.7.1 в шапке и «Что нового?».
2. Выбрать три пресета по очереди и проверить понятность подсказок. «Все» → «Ничего» → любой пресет: галочки должны меняться, файловые операции не начинаться.
3. Проверить экспертный режим только на уровне выбора; опасные операции испытывать в подготовленной VM. Во время анализа пресеты и «Все»/«Ничего» недоступны; после отмены доступны снова.
4. Проверить RU/EN, небольшой экран и реальный масштаб Windows 100–200%, доступ с клавиатуры. Рендеры не заменяют такие испытания.
5. Старый beta.7 может не распознавать beta.7.1 в проверке обновлений; для перехода использовать страницу GitHub Releases и полный ZIP. Эта сборка уже умеет сравнивать такие номера.

Для публикации: тег `v1.1.0-beta.7.1`, статус pre-release, ZIP и при желании `.sha256`; описание RU/EN — [RELEASE_NOTES.md](../../RELEASE_NOTES.md). Сначала зафиксировать и отправить соответствующие исходники. Матрица реальных Windows-испытаний из [beta.7](BETA7_VALIDATION.md) остаётся открытой.
